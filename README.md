# Smart Hotel Management System

This repository is now rooted at the `Smart-Hotel-Booking-System` directory. It contains two main subfolders:

* `client` – the frontend React/Vite application
* `server` – the backend Node/Express API

Each folder has its own `package.json` and can be developed and deployed independently. There is no integration yet – the structure simply separates client and server code for version control.

To start working:

```bash
# frontend
cd client && npm install && npm run dev

# backend
cd ../server && npm install && npm start
```

You shouldn't need to rename or remove anything now; this README and a `.gitignore` live at the repository root (`Smart-Hotel-Booking-System`).# Hotel-Manager-Fix
# Process to run the Application

1. Download the zip file and extract it and open in VS Code
2. Add env file in root directory
3. cd server → npm i
4. npm run start 
5. In Compass connect the database
6. Kill the server in terminal
7. Run npm run seed → npm run start
8. Refresh Compass
9. cd client → npm i → npm run dev
